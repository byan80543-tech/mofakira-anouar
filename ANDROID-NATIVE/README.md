# مفكرة أنوار — Android Native

تطبيق أندرويد مستقل للكتابة والملاحظات، مبني بـ Kotlin وJetpack Compose. لا يستخدم WebView ولا يحتاج إلى اتصال بالإنترنت.

## الوظائف

- واجهة عربية واتجاه RTL.
- إنشاء الملاحظات وتعديلها وحذفها.
- حفظ تلقائي بعد توقف الكتابة لمدة تقارب 550 مللي ثانية.
- الحفظ قبل مغادرة المحرر، مع عدم إنشاء ملاحظة فارغة.
- قاعدة بيانات Room محلية على الهاتف.
- البحث داخل العناوين والنصوص.
- عرض تاريخ آخر تعديل وعدد الأحرف.
- لا يطلب أذونات إنترنت أو موقع أو ميكروفون.

## بنية المشروع

- `app/src/main`: التطبيق الأصلي وواجهة Compose.
- `data/Note.kt`: نموذج الملاحظة.
- `data/NoteDao.kt`: عمليات قاعدة البيانات والبحث.
- `data/NotesDatabase.kt`: قاعدة Room المحلية.

## إعدادات البناء

- Android Gradle Plugin: 8.10.2
- Kotlin: 2.2.20
- KSP: 2.2.20-2.0.4
- Gradle: 8.11.1
- JDK: 17
- compileSdk / targetSdk: 36
- minSdk: 26
- Room: 2.8.5

## بناء APK

يحتوي المستودع على سير عمل GitHub Actions باسم **Android Native Notes APK**. يُشغّل عند فتح طلب دمج يتضمن تغييرات في هذا المجلد، كما يمكن تشغيله يدوياً. عند نجاح البناء، يرفع ملف `app-debug.apk` كأثر بناء قابل للتنزيل لمدة 14 يوماً.

للبناء محلياً، افتح مجلد `ANDROID-NATIVE` في Android Studio مع تثبيت JDK 17 وAndroid SDK 36 وGradle 8.11.1، ثم نفّذ مهمة `assembleDebug`.

## الخصوصية والحدود

الملاحظات محفوظة في قاعدة بيانات التطبيق المحلية. لا يحتوي هذا الإصدار على تسجيل دخول أو مزامنة سحابية أو تحليلات أو أذونات شبكة. ملف Debug APK مخصص للاختبار، وليس إصداراً موقعاً للنشر في Google Play.

لا يُعتمد الإصدار قبل نجاح البناء واختبار الإنشاء والحفظ التلقائي والبحث والحذف على جهاز Android فعلي.

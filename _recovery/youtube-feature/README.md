# استعادة ميزة YouTube Transcript — مفكرة أنوار

هذه نسخ احتياطية كاملة للملفات قبل إزالة ميزة توليد النص من رابط YouTube.
لا تُحمّل هذه الملفات فوق النسخة الحالية إلا عند الرغبة في التراجع الكامل.

- index.html.before-youtube-removal: نسخة الواجهة الأصلية.
- app-core.js.before-youtube-removal: نسخة منطق التطبيق الأصلية.
- workers/anwar-api-gateway/src/index.mjs.before-youtube-removal: نسخة بوابة API الأصلية.

التعديل يجري على الفرع remove-youtube-transcript-safe فقط، ولا يغيّر main.

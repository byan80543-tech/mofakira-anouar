# مختبر السبحة الصوتية المحلية — v0.1

هذه مساحة تجريبية مستقلة عن السبحة الأساسية. لا تعدّل ملفات التطبيق المستقر.

## ما الذي تثبته هذه المرحلة؟
- طلب إذن الميكروفون بعد ضغط المستخدم فقط.
- التقاط الإشارة عبر getUserMedia.
- حساب RMS داخل AudioWorklet وإرسال قيمة رقمية محلية إلى واجهة الصفحة.
- لا تستخدم Web Speech API أو مكتبات أو نماذج خارجية.
- لا تسجل الصوت في ملف ولا ترسله الصفحة إلى خادم.
- إيقاف مسارات الميكروفون وإغلاق AudioContext عند الضغط على إيقاف.

## ما الذي لا تفعله؟
- لا تتعرف على «سبحان الله» أو غيرها.
- لا تزيد العداد تلقائياً؛ زر الزيادة اليدوية للاختبار فقط.
- لا تثبت وحدها انعدام كل اتصالات الشبكة على مستوى المتصفح أو الجهاز.
- لا تثبت بعد دقة التعرف أو استهلاك البطارية.

## الاختبار على الهاتف
1. افتح الصفحة عبر HTTPS في Chrome.
2. اضغط «بدء اختبار الميكروفون» واسمح بالميكروفون.
3. تحدث أو قل ذكراً ولاحظ مؤشر مستوى الإشارة؛ لا تتوقع زيادة العداد.
4. اضغط «إيقاف» وتأكد من توقف مؤشر الميكروفون.
5. بعد تحميل الصفحة وملفاتها، فعّل وضع الطيران وأعد فتح الصفحة إن كانت متاحة من الذاكرة المؤقتة، ثم اختبر مجدداً.
6. راقب طلبات الشبكة في DevTools إن أمكن. لا تعتبر نجاح وضع الطيران وحده تدقيقاً شاملاً لكل حركة الجهاز.

## المرحلة التالية
إضافة نموذج تصنيف صوتي عربي محلي بملفات مستضافة على نفس الأصل، ثم اختباره على عينات متنوعة تشمل الذكر والصمت والكلام العادي والضوضاء، مع قياس الإيجابيات الكاذبة قبل السماح بأي عد تلقائي.

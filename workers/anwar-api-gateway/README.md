# بوابة أنوار لواجهات API

هذه البوابة وسيط محدود الوظائف لخدمات بيانات مفكرة أنوار. ليست وكيل URL مفتوحًا، ولا تقبل عنوانًا خارجيًا يختاره الزائر.

## المسارات المسموحة

- `GET /v1/reciters` — قائمة القراء من MP3Quran.
- `GET /v1/radios` — قائمة المحطات من MP3Quran.
- `GET /v1/country/list?nationality=MA&page=1` — صفحة بلد من Way2Quran. رموز البلدان مقيدة بالقائمة الموجودة في الكود.
- `GET /v1/country/profile?slug=...` — ملف قارئ من Way2Quran، مع فحص صيغة المعرّف.

أي مسار آخر أو أي مضيف خارجي يحدده العميل مرفوض.

## حدود الطلبات المبدئية

الحدود نافذة منزلقة مدتها 60 ثانية، وتُحسب لكل عنوان IP:

| الفئة | الحد |
|---|---:|
| جميع مسارات البوابة مجتمعة | 120 طلبًا |
| فهرس القراء والمحطات | 30 طلبًا |
| صفحات البلدان | 12 طلبًا |
| ملفات القراء | 24 طلبًا |

عند تجاوز الحد تعيد البوابة `429` و`Retry-After`. يستخدم المحدد Durable Object واحدًا لكل عنوان IP، ويخزن بصمة SHA-256 للعنوان بدل حفظ العنوان الخام. التخزين المؤقت يقلل الوصول إلى مزودي البيانات: ساعة لقائمة القراء، 30 دقيقة للمحطات، 10 دقائق لصفحات البلدان، و15 دقيقة للملفات.

**ملاحظة عدالة:** قد يشترك عدد من زوار شبكات الهاتف في عنوان IP عام واحد. لذلك قد يشتركون في الحد نفسه. نبدأ بهذه القيم ونراقب الاستخدام قبل خفضها. حدود Durable Object عالمية لكل بصمة عميل، وليست مجرد عدادات محلية متفرقة.

## النشر

الموقع الحالي على GitHub Pages، وهو استضافة ثابتة. لا يمكن نشر كود هذه البوابة على GitHub Pages نفسه؛ يجب نشرها كـCloudflare Worker مستقل.

1. أنشئ/سجّل الدخول إلى حساب Cloudflare.
2. ثبّت Node.js ثم شغّل:
   `npx wrangler login`
3. انتقل إلى مجلد `workers/anwar-api-gateway` وشغّل:
   `npx wrangler deploy`
4. سيظهر عنوان من النمط `https://anwar-api-gateway.<account-subdomain>.workers.dev`.
5. انسخ العنوان كاملًا إلى `api-gateway-config.js` في جذر المشروع، داخل قيمة `ANWAR_API_GATEWAY_BASE`، ثم ارفع هذا التعديل إلى GitHub.

القيمة الفارغة في ملف الإعداد تعني أن الواجهة تستمر مؤقتًا في الاتصال المباشر بالمصادر الحالية؛ **لن تكون بوابة الشبكة فعّالة للزوار حتى تُنشر وتُضبط قيمتها**.

## الاختبار بعد النشر

- افتح `/v1/reciters` و`/v1/radios` من صفحة المفكرة.
- راقب عمود Network: يجب أن تمر الطلبات عبر عنوان Worker بدل MP3Quran أو خدمات CORS proxy.
- كرر طلبات الاختبار من نفس الشبكة حتى تتلقى `429` مع `Retry-After`.
- تأكد أن طلبًا إلى مسار عشوائي أو URL خارجي يُرفض.
- تحقق من أن إعادة فتح الإذاعة خلال صلاحية الكاش لا تضيف طلبًا إلى مزود البيانات.

## حدود هذه الطبقة

هذه البوابة تحمي طلبات **البيانات** التي تمر عبرها. ملفات MP3 والبث المباشر ما زالت تُحمّل من مضيفي الصوت مباشرة حتى لا نمرر تدفقًا كبيرًا عبر Worker. كما أنها لا تمنع هجومًا موزعًا واسعًا من آلاف العناوين على Worker نفسه؛ عند ربط نطاق مخصص بـCloudflare يمكن إضافة WAF Rate Limiting Rules وتحديات البوتات عند الحافة. لا تجعل CORS وحده وسيلة مصادقة؛ يمكن لأي عميل غير متصفح تزوير ترويسة Origin.

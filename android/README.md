# تطبيق أنوار المرافق للأذان الخلفي

مشروع Android مرافق لواجهة مفكرة أنوار. يفتح الموقع نفسه داخل WebView، ويتلقى إعدادات الصلاة عبر Web Message Listener المقيد إلى أصل الموقع:
`https://mofakira-anouar.pages.dev`.

## ما يفعله الإصدار الأول

- يقرأ البلد والمدينة وطريقة الحساب والمذهب والصوت ومستوى الصوت من إعدادات مواقيت الصلاة.
- يجلب تقويم الشهر الحالي والشهر التالي من AlAdhan API ويحفظ مواعيد الصلوات الخمس محليًا.
- يجدول المنبه التالي عبر `AlarmManager` ثم يجدول الصلاة التالية عند إطلاق المنبه.
- يعيد تسجيل المنبه بعد إعادة تشغيل الهاتف أو تغيير الساعة والمنطقة الزمنية.
- يستخدم خدمة تشغيل وسائط أمامية لتشغيل الأذان خارج صفحة WebView، ويحاول حفظ الملف الصوتي محليًا كي يمكن تشغيله دون اتصال لاحقًا.
- يطلب إذن الإشعارات على Android 13+ وإذن المنبهات الدقيقة من إعدادات النظام على Android 12+.

## حدود الإصدار الأول

- يجب فتح المفكرة داخل هذا التطبيق المرافق مرة واحدة على الأقل، ثم تفعيل الأذان التلقائي من إعدادات المواقيت.
- لا تنتقل إعدادات Local Storage من نسخة Chrome/PWA المثبتة تلقائيًا إلى WebView؛ راجع المدينة وطريقة الحساب والصوت داخل التطبيق المرافق.
- التسجيل المغربي القديم المرتبط بيوتيوب لا يعمل كملف خلفي في هذا الإصدار. اختر «أذان هادئ» أو «المسجد النبوي» مؤقتًا حتى تضاف ملفات مغربية مباشرة ومسموح باستخدامها.
- إذا رُفض إذن المنبهات الدقيقة، يستخدم التطبيق منبهًا تقريبيًا قد يتأخر مع وضع السكون؛ لا يمكن ضمان التوقيت الدقيق حتى يُمنح الإذن.
- إيقاف التطبيق إجباريًا من إعدادات Android يمنع النظام من إعادة تشغيله حتى يفتحه المستخدم مجددًا.
- يجب اختبار التشغيل على الجهاز الفعلي، خاصة إعدادات البطارية والسماح بالتنبيه في شاشة القفل.

## بناء APK تجريبي

من GitHub Actions شغّل سير العمل **Build Anwar Android Companion**. سيُنتج ملف Debug APK داخل Artifact باسم `anwar-android-debug-apk`. هذا بناء تجريبي غير مخصص للنشر على Google Play.

المتطلبات: JDK 17، Android SDK 36، Gradle 8.13، Android Gradle Plugin 8.13.2.

# تطبيق مفكرة أنوار لأندرويد

هذا مجلد تطبيق Android الأصلي لمفكرة أنوار. بدأ المشروع مرحلة الانتقال من واجهة ويب مع خدمات أذان أصلية محدودة إلى تطبيق Android مستقل تدريجيًا، مع إبقاء جميع خدمات النسخة الحالية متاحة أثناء النقل.

## الحالة الحالية

- أصبحت `MainActivity` شاشة دخول أصلية مبنية بعناصر Android Views ولا تحمّل الموقع داخلها.
- تعرض شاشة البداية هوية المفكرة وأقسام خدماتها، وتتيح فتح النسخة الكاملة الحالية من زر «فتح جميع خدمات المفكرة».
- نُقلت تجربة الموقع الحالية مؤقتًا إلى `LegacyWebActivity`. تبقى هذه الشاشة متاحة حتى ننقل كل خدمة ونختبر تكافؤها؛ لا تحذفها قبل اكتمال النقل.
- جسر `AnwarAdhanBridge` وعمليات طلب أذونات الأذان ما زالت ضمن شاشة التوافق، ولذلك فإن إعداد الأذان من الواجهة الحالية يتم عبر فتح «جميع خدمات المفكرة».
- توجد بنية Android أصلية قائمة لجدولة الصلاة وتشغيل تسجيل الأذان الخلفي، وتبقى قيد الاختبار والتحسين.

## الأذان في الخلفية

تستخدم البنية الحالية:
- `AlarmManager` لجدولة الصلاة التالية.
- `PrayerAlarmReceiver` لتشغيل حدث الأذان وجدولة الصلاة التالية.
- `BootReceiver` لإعادة الجدولة عند إعادة تشغيل الهاتف أو تغير الوقت والمنطقة الزمنية أو تحديث التطبيق.
- `PrayerRefreshWorker` لتحديث تقويم المواقيت.
- `AdhanPlaybackService` لتشغيل التسجيل كخدمة وسائط أمامية.

يحتاج Android 13+ إلى إذن الإشعارات، ويحتاج Android 12+ إلى إذن «المنبهات والتذكيرات» والسماح بالمنبهات الدقيقة كي يمكن ضمان التوقيت الدقيق وفق قيود النظام. إذا رُفض الإذن فقد يستخدم التطبيق جدولة تقريبية. وقد تؤثر إعدادات توفير الطاقة أو الإيقاف الإجباري في تشغيل الخلفية.

نسخة Chrome أو PWA وحدها لا تستطيع منح تطبيق Android أذونات النظام؛ يجب إجراء إعداد الأذان من داخل تطبيق مفكرة أنوار لأندرويد، عبر شاشة خدمات التوافق الحالية مؤقتًا.

## الانتقال دون فقد الميزات

- لا يُحذف أي قسم أو محتوى من نسخة الويب خلال عملية النقل.
- تبقى نسخة الويب وPWA مستقلة ومتاحة.
- تُنقل الخدمات إلى شاشات Android أصلية تدريجيًا، كل خدمة على حدة.
- يجب جرد البيانات المحلية وتوفير تصدير/استيراد قبل نقل الإعدادات أو السجلات.
- لا تعتبر شاشة البداية الأصلية وحدها اكتمال التحول؛ اكتماله مشروط بأن تصبح الخدمات نفسها أصلية وأن تجتاز اختبارات القبول.

## البناء

من GitHub Actions شغّل سير العمل **Build Anwar Android Companion**. سينتج ملف Debug APK داخل Artifact باسم `anwar-android-debug-apk`. هذا بناء اختباري وليس إصدارًا موقّعًا للنشر على Google Play.
